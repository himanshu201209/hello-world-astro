# Blog (Webflow Cloud)

Independent Astro app for the `/blog` Webflow Cloud mount path.

## Commands

| Command | Action |
| :------ | :----- |
| `npm install` | Installs dependencies |
| `npm run dev` | Starts the Astro dev server |
| `npm run build` | Builds the production site |
| `npm run preview` | Runs `astro build` then `wrangler dev` |

Mount path placeholder: `CLOUD_MOUNT_PATH` (replaced with `/blog` by Webflow Cloud).
